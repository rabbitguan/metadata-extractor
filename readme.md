# 科技资源模型双向映射工具

## 项目简介
科技资源模型双向映射工具是一个 Chrome 浏览器插件，能够智能提取当前网页中的科技资源信息，通过大语言模型自动整理为结构化的元数据，并支持中英文双语展示。
该工具特别适用于科研人员、数据管理员和科技资源平台用户，可快速从网页中提取数据集、数据论文、标准文献等科技资源的元数据信息。

## 功能特性

### 核心功能

- **智能内容提取**：自动提取当前网页的文本内容
- **大模型驱动**：调用通义千问大语言模型进行智能分析和信息提取
- **资源类型识别**：自动判断网页内容属于数据集、数据论文等等类型
- **双模式展示**：
  - **通用元数据模式**：展示核心元数据字段（标识符、资源名称、描述、关键词等）
  - **领域专用模式**：根据资源类型展示对应的领域元数据（数据集元数据、数据论文元数据等）
- **中英文双语**：同时生成中英文两个版本的元数据
- **扩展信息**：大模型额外提取的重要信息（如使用注意事项、项目信息、研究亮点等）
- **一键下载**：支持下载元数据为 JSON 文件（不含扩展信息）

### 支持的元数据标准

- **核心元数据**：通用科技资源元数据（15+ 字段）
- **数据集元数据**：数据集专用元数据（基本信息、出版信息、服务信息等）
- **数据论文元数据**：数据论文专用元数据（内容信息、出版信息、服务信息等）
- **标准文献元数据**：标准文献专用元数据（60+ 字段）
- **生态科学数据元数据**：生态科学领域专用元数据

## 技术架构

### 后端服务 (Python)

- **框架**：Flask + CORS
- **大模型**：阿里云通义千问 (qwen3-8b)
- **核心模块**：
  - `backend.py`：API 服务入口
  - `llm_api.py`：大模型调用和 Prompt 管理
  - `field_filter.py`：字段过滤和空值处理
  - `identifier.py`：标识符识别（DOI、CSTR、专利号等）

### 前端插件 (Chrome Extension)

- **技术栈**：Manifest V3 + Chrome Side Panel API
- **核心文件**：
  - `manifest.json`：插件配置文件
  - `background.js`：后台服务 Worker
  - `content.js`：内容脚本
  - `sidepanel/sidepanel.html`：侧边栏界面
