# 元数据提取服务输入输出接口文档

## 1. 基本信息

- 服务地址：`http://127.0.0.1:4000`
- 远程示例地址：`http://8.130.186.178:21097`
- 请求格式：`application/json`
- 响应格式：`application/json`
- 主要接口：
  - `POST /register`：提交网页、URL、文本或上传 JSON/XML，提取元数据。
  - `POST /query`：提交 DOI/CSTR 标识符，解析后提取元数据。

---

## 2. 文本、网页、URL、上传文件元数据提取

### 接口地址

`POST /register`

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `source` | string | 否 | 输入来源。可选值：`text`、`web`、`url`、`upload`。默认 `text`。 |
| `mode` | string | 否 | 提取模式。可选值：`common`、`domain`。默认 `common`。 |
| `strategy` | string | 否 | 提取策略。可选值：`auto`、`llm`、`rule`、`upload_rule`。默认 `auto`。 |
| `force_reanalyze` | boolean/string | 否 | 是否跳过历史缓存并重新分析。支持 `true`、`false`、`"1"`、`"true"`。默认 `false`。 |
| `text` | string | 条件必填 | 待分析文本。当 `source=text/web/upload` 时需要提供。 |
| `html` | string | 否 | 页面 HTML，用于规则提取和历史记录保存。 |
| `url` | string | 条件必填 | 页面地址。当 `source=url` 时必填。 |
| `title` | string | 否 | 页面标题或上传文件名。文件名以 `.json` 或 `.xml` 结尾时会按结构化上传解析。 |

### 输入示例：文本内容

```json
{
  "source": "text",
  "mode": "common",
  "strategy": "auto",
  "text": "Title: A Multi-Source Urban Water Quality Dataset for Seasonal Analysis\n\nThis study presents a multi-source urban water quality dataset collected from 18 monitoring sites. DOI: 10.1234/jeds.2025.0318. The dataset includes CSV tables, calibration logs, sensor metadata, sampling schedules, and a README.",
  "title": "mock_paper_dataset_input.txt"
}
```

### 输入示例：URL 直抓

```json
{
  "source": "url",
  "mode": "common",
  "strategy": "auto",
  "url": "https://arxiv.org/abs/2605.30822"
}
```

### 输入示例：网页 HTML

```json
{
  "source": "web",
  "mode": "domain",
  "strategy": "auto",
  "url": "https://example.org/paper",
  "title": "Example Data Paper",
  "text": "页面正文文本...",
  "html": "<html><head><title>Example Data Paper</title></head><body>...</body></html>"
}
```

### 输入示例：上传 JSON

上传 JSON/XML 时，`source` 使用 `upload`，`text` 放文件原始内容，`title` 建议保留文件名。

```json
{
  "source": "upload",
  "mode": "common",
  "title": "data-paper-valid.json",
  "text": "{\n  \"resource_type\": \"data_paper\",\n  \"core\": {\n    \"title\": \"A Data Paper for Scientific Metadata Benchmarking\",\n    \"cstr_identifier\": \"31253.11.CSTR.2026.000002\",\n    \"creators\": [\"Chen Wang\", \"Maria Smith\"],\n    \"publisher\": \"Journal of Example Data\",\n    \"publication_date\": \"2026-05-18\",\n    \"description\": \"This data paper describes a benchmark dataset and its construction workflow.\",\n    \"keywords\": [\"data paper\", \"metadata\", \"benchmark\"],\n    \"subjects\": [\"Data Science\"],\n    \"language\": \"en\",\n    \"alternative_identifiers\": [\"10.5678/example.datapaper.002\"],\n    \"resource_url\": [\"https://example.org/papers/metadata-benchmark\"]\n  }\n}"
}
```

## 3. DOI/CSTR 标识符解析并提取元数据

### 接口地址

`POST /query`

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `source` | string | 否 | 固定建议传 `identifier`。 |
| `mode` | string | 否 | 提取模式。可选值：`common`、`domain`。默认 `common`。 |
| `identifiers` | string/array | 条件必填 | DOI/CSTR 字符串或数组。 |
| `text` | string | 条件必填 | 不传 `identifiers` 时，可从文本中自动提取 DOI/CSTR。 |
| `html` | string | 条件必填 | 不传 `identifiers` 和 `text` 时，可从 HTML 中自动提取 DOI/CSTR。 |

说明：`identifiers` 优先级最高；未传时依次从 `text`、`html` 中提取 DOI/CSTR。

### 输入示例：单个 DOI

```json
{
  "source": "identifier",
  "mode": "common",
  "identifiers": "10.48550/arXiv.2303.14524"
}
```

### 输入示例：多个 DOI/CSTR

```json
{
  "source": "identifier",
  "mode": "domain",
  "identifiers": [
    "10.48550/arXiv.2303.14524",
    "31253.11.CSTR.2026.000002"
  ]
}
```

### 成功响应（200）

```json
{
  "items": [
    {
      "identifier": "10.48550/arXiv.2303.14524",
      "type": "doi",
      "resolved_url": "https://doi.org/10.48550/arXiv.2303.14524",

        "zh": {
          "核心元数据": {
            "标题": "示例标题",

            "扩展信息": "未提取到"
          },
          "数据论文元数据": {
            "数据论文内容信息": {
              "摘要": "..."
            }
          }
        },
        "en": {
          "Core Metadata": {
            "Title": "Example Title",
            "ResourceType": "Data Paper",

```

说明：`items` 中允许同时存在 `status=ok` 和 `status=error`。只要至少一个标识符解析成功，接口整体返回 `200`。

### 失败响应

#### 未识别 DOI/CSTR（400）

```json
{
  "status": "error",
  "message": "No DOI or CSTR identifier found"
}
```

#### 全部标识符解析失败（400）

```json
{
  "status": "error",
  "message": "Failed to resolve any DOI or CSTR identifier",
  "errors": [
    {
      "identifier": "10.1000/xyz123",
      "type": "doi",
      "message": "..."
    }
  ]
}
```

## 4. 输出字段结构说明

### 顶层结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `zh` | object | 中文元数据结果。 |
| `en` | object | 英文元数据结果。 |
| `items` | array | `/query` 接口返回的多标识符结果列表。 |

### 中文结果结构

| 路径 | 说明 |
| --- | --- |
| `zh.核心元数据` | 所有资源通用的核心元数据字段。 |
| `zh.数据集元数据` | 当资源被判定为数据集时返回。 |
| `zh.数据论文元数据` | 当资源被判定为数据论文时返回。 |
| `zh.其他元数据` | 当资源被判定为其他类型时返回。 |

### 英文结果结构

| 路径 | 说明 |
| --- | --- |
| `en.Core Metadata` | 所有资源通用的核心元数据字段。 |
| `en.Dataset Metadata` | 当资源被判定为数据集时返回。 |
| `en.Data Paper Metadata` | 当资源被判定为数据论文时返回。 |
| `en.Other Metadata` | 当资源被判定为其他类型时返回。 |

### 空值占位

后端会补齐必需字段。未提取到的字段使用以下占位值：

| 语言 | 占位值 |
| --- | --- |
| 中文 | `未提取到` |
| 英文 | `Not extracted` |

## 5. 调用示例

### 本地调用 `/register`

```bash
curl -X POST http://127.0.0.1:4000/register \
  -H "Content-Type: application/json" \
  -d '{
    "source": "text",
    "mode": "common",
    "strategy": "auto",
    "text": "Title: Example Data Paper. DOI: 10.1234/example."
  }'
```

### 远程调用 `/register`

```bash
curl -X POST http://8.130.186.178:21097/register \
  -H "Content-Type: application/json" \
  -d '{
    "source": "url",
    "url": "https://arxiv.org/abs/2303.14524",
    "mode": "common",
    "strategy": "auto"
  }'
```

### 本地调用 `/query`

```bash
curl -X POST http://127.0.0.1:4000/query \
  -H "Content-Type: application/json" \
  -d '{
    "source": "identifier",
    "mode": "common",
    "identifiers": "10.48550/arXiv.2303.14524"
  }'
```

### 远程调用 `/query`

```bash
curl -X POST http://8.130.186.178:21097/query \
  -H "Content-Type: application/json" \
  -d '{
    "source": "identifier",
    "mode": "common",
    "identifiers": "10.48550/arXiv.2303.14524"
  }'
```
